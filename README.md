#  LifeLink

LifeLink is a web application designed to bridge the gap between patients in need of blood and suitable blood donors. The goal of the project is to make it easier for hospitals to create urgent blood requests while helping donors connect with people who need their support.

> **Project Status:**  Under Development

##  About the Project

LifeLink was developed as a university project and is being expanded with the goal of becoming a practical solution that can be used in real-world healthcare settings.

The platform focuses on making blood donation requests more organized and accessible by providing separate experiences for hospitals and blood donors.

##  Features

*  Register as a blood donor
*  Register as a hospital
*  Separate sign-in system for donors and hospitals
*  Individual dashboards for each user type
*  Create urgent blood requests (Hospital)
*  Edit existing blood requests
*  Cancel blood requests
*  Clean and user-friendly interface

##  Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

##  Future Improvements

* Database integration
* Real-time notifications
* Blood donor matching based on blood type and location
* Improved authentication and security
* Mobile responsiveness
* Deployment for public use

##  Project Goal

The long-term vision of LifeLink is to become a platform that helps connect hospitals, blood donors, and patients more efficiently, making it easier to respond to urgent blood donation needs.
